# Домашнее задание 1: табличные данные

* `hw1_A.ipynb` — часть A, регрессия (RMSE).
* `hw1_B.ipynb` — часть B, классификация (ROC-AUC).

Данные ноутбук скачивает сам (раздел 0) в папку `data_A/` или `data_B/` рядом с собой — один раз, пока её нет.
В каждой папке `data_*`: `train.csv` и `public_test.csv` (с `target`), `task.md` (задание и колонки),
`submission.py` (сохранение модели для сдачи), `dataset.json` (служебный), `sample_submission.csv`
и `check_submission.py` (формат прогнозов — для самопроверки).

**Сдача.** В разделе 9 каждого ноутбука `save_model(final_model, "Фамилия_Имя")` создаёт
`hw1_A_Фамилия_Имя.model` и `hw1_B_Фамилия_Имя.model` — сохраняйте их в Colab (там же модели запускает преподаватель)
и сразу скачивайте: временное хранилище Colab очищается. В LMS сдаётся один архив `hw1_Фамилия_Имя.zip` —
оба ноутбука и обе модели, и больше ничего.
