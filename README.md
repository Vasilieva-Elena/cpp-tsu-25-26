# ООП-терминал на C++

Простой файловый менеджер с поддержкой навигации, CRUD-операций и полиморфного редактирования текстовых файлов (однострочные/многострочные). Демонстрирует принципы объектно-ориентированного проектирования: инкапсуляцию, наследование, полиморфизм, абстракцию.

## Особенности

- Иерархия классов `Entry` → `Directory`, `SingleLineFile`, `MultiLineFile`, `PostponedFile`.
- Полиморфный метод `edit()` – разное поведение в зависимости от типа файла.
- Мягкое удаление (скрытие) с возможностью восстановления.
- Отложенное определение типа файла (`PostponedFile`) до первого редактирования.
- Навигация по директориям (вверх/вниз).
- CRUD: создание, чтение, обновление, удаление.

## Запуск

g++ -std=c++17 -Iinclude main.cpp src/*.cpp -o terminal
./terminal
